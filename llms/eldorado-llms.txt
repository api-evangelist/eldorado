# El Dorado API

> El Dorado is a stablecoin-powered payments SuperApp for Latin America. Its public API provides crypto onramp/offramp (buy and sell) infrastructure that converts between local fiat currencies (USD, ARS, BRL, COP, PEN and more) and crypto settled in USDT on Arbitrum, with built-in KYC, 80+ local payment methods, and an embeddable Exchange Widget. Backed by Multicoin Capital, Coinbase Ventures and Berkeley SkyDeck.

Base URLs: production https://api.eldorado.io/api/ , testnet https://api-testnet.eldorado.io/api/
Authentication: X-Client-ID + X-Referral-ID headers (issued via api@eldorado.io) plus a JWT bearer token from an email OTP login. Trading requires KYC level L2+.

## Operations
- POST /auth/login/send-otp — send email OTP
- POST /auth/login/verify-otp — verify OTP, get JWT
- GET /kyc — get KYC status ; POST /kyc — submit KYC ; POST /kyc/phone — verify phone
- GET /currencies — supported currencies ; GET /countries — supported countries ; GET /payment-methods — payment methods
- POST /quote/buy — buy (fiat->crypto) quote ; POST /quote/sell — sell (crypto->fiat) quote
- Create/get orders from a quote (apiOrderId)
- GET /clock — server time / health
